# School Facilities and Equipment Concern Tracker

## Problem Statement

Medina College Ipil needs a simple system where students and staff can report concerns about school facilities and equipment.

## FR-01: Report a Concern

The system must allow users to submit a concern by providing:
- Concern category
- Location
- Item or facility name
- Date reported
- Description

All fields are required. The system must reject invalid and future dates.

The system must save submitted concerns in localStorage and display saved records even after refreshing the page.

The application must use a simple and clean design.
